# Unit 2 – Social Network Adjacency Matrix Case Study

This folder contains a GitHub-ready case study covering:

- Array and Array as an Abstract Data Type (ADT)
- Array operations
- Storage representation
- 2D and nD arrays
- Sparse matrix representation
- Sequential/Linear Search
- Binary Search
- Fibonacci Search
- Indexed Sequential Search
- Sorting concepts: stability, efficiency, number of passes
- Internal and External Sorting
- Bubble Sort
- Insertion Sort
- Selection Sort
- Quick Sort
- Merge Sort
- Case Study: Social Network Adjacency Matrix

## Files

- `case-study.md` – Complete case study and theory
- `adjacency_matrix.py` – Basic adjacency matrix implementation
- `sparse_matrix.py` – Sparse matrix/triplet representation

## Run Python examples

```bash
python adjacency_matrix.py
python sparse_matrix.py
```
