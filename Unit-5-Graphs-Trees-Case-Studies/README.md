# SPPU PCC-201-COM Data Structures - Unit V Case Studies

## Unit V - Graphs and Trees

This repository contains the two case studies specified in the
SPPU Second Year Computer Engineering (2024 Pattern) Data Structures
syllabus.

### Case Study 1 - GPS / Navigation System

Models a city map as a weighted graph and demonstrates:

- BFS
- DFS
- Dijkstra's shortest path
- Prim's MST
- Kruskal's MST

Folder:
`01-GPS-Navigation-Weighted-Graph/`

### Case Study 2 - ZIP/GZIP File Compression

Demonstrates frequency-based Huffman encoding using a binary Huffman
tree.

Folder:
`02-ZIP-GZIP-Huffman-Compression/`

Both projects are educational implementations aligned with the
PCC-201-COM Unit V syllabus.
