### 1. E-Commerce Product Sorting

* **Strategy:** Divide and Conquer
* **Algorithm:** Merge Sort
* **Purpose:** Sort e-commerce products according to price
* **Time Complexity:** O(n log n)

### 2. Google Calendar Application

* **Strategy:** Greedy
* **Algorithm:** Activity Selection
* **Purpose:** Select maximum number of non-overlapping calendar events
* **Time Complexity:** O(n log n)

### 3. Social Network Adjacency Matrix

* **Data Structure:** 2D Array / Sparse Matrix
* **Technique:** Adjacency Matrix Representation
* **Purpose:** Represent friendship connections between millions of users
* **Time Complexity:** O(1) for direct connection checking

### 4. Stack and Queue using Linked Lists

* **Data Structure:** Linked List
* **Operations:** Push, Pop, Enqueue, Dequeue
* **Purpose:** Implement Stack and Queue dynamically using linked lists
* **Time Complexity:** O(1) for basic operations
